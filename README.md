# Regresión Lineal por Mínimos Cuadrados

## Descripción
Este proyecto realiza un cálculo de regresión lineal utilizando el método de mínimos cuadrados en Java.

El programa permite obtener la pendiente, el intercepto, el coeficiente de correlación de Pearson y el coeficiente de determinación.

## Objetivo
Aplicar el método de mínimos cuadrados para encontrar la recta que mejor se ajusta a un conjunto de datos.

## Datos utilizados

| X | Y |
|---|---|
| 1 | 2 |
| 2 | 4 |
| 3 | 5 |
| 4 | 4 |
| 5 | 6 |

## Resultados
- Pendiente: 0.8000
- Intercepto: 1.8000
- Coeficiente de Pearson (r): 0.8165
- Coeficiente de determinación (r²): 0.6667
- Predicción para X = 6: 6.6000

## Archivos del proyecto
- RegressionLineal.java: contiene los cálculos de regresión lineal.
- Main.java: ejecuta el programa y muestra los resultados.
